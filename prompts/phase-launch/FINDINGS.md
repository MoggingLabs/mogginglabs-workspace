# FINDINGS — the routing ledger

Every defect Part I finds, and where it went. `scripts/check-launch-audit.mjs`
reads this file to **derive** each row's grade: for any (`INVENTORY.md` row,
lens), **A ≡ zero unresolved findings**. Nobody types a letter.

**Seed state (step 01): the ledger is empty.** Steps 02–07 fill it. An empty
ledger is not a clean bill of health — it means no lens has been swept yet, which
is exactly what `INVENTORY.md`'s `~NN` pending markers say out loud.

## The columns

| column | rule |
| --- | --- |
| **id** | `F001`, `F002`, … unique, never reused. A retracted finding stays in the table as `invalid`; it is not deleted. |
| **area** | the `INVENTORY.md` row this lands on, as `#<id>` (e.g. `#42`). A finding with no row has no denominator — it cannot move a grade, so the gate refuses it. |
| **lens** | one of `corr` · `smell` · `spag` · `dup` · `eff` · `debt` (see `RUBRIC.md`). |
| **file:line** | where the defect is. The file must exist. |
| **sev** | `S1` · `S2` · `S3`. Orders the queue; never decides whether to fix. |
| **verdict** | `fixed` or `invalid`. **Those are the only two.** |
| **evidence** | for `fixed`, the assertion that goes **red on the pre-fix bytes**; for `invalid`, the reproduction attempt and the word **DISPROVEN**. |
| **resolved-in** | the step / commit / gate that landed it. Required for `fixed`. |

## The rules the gate enforces

1. **Two verdicts.** `open`, `defer`, `wontfix`, `accepted`, `known` are named
   and rejected by the gate. They are the vocabulary of shipping a defect you
   already found — and finding it was the expensive part.
2. **`fixed` needs a bite proof.** The evidence must name an assertion (gate,
   smoke, unit) that was **red before the fix**. A fix with no failing test
   behind it is a story about a fix.
3. **`invalid` needs a disproof.** The evidence must contain **DISPROVEN** and
   show the attempt. "I don't think that can happen" is not a disposition.
4. **A finding reds the sweep until it is resolved.** That is deliberate and it
   is the forcing function: filing a defect makes the build honest about
   carrying one, so the queue drains instead of accreting.
